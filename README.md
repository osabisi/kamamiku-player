# かまみくプレーヤー

オモコロの「かまってみくのしん」の過去回を、続きから聴くための非公式プレーヤーです。初代、GOLD、日本一、Love youの4シリーズを掲載しています。

## GitHub Pagesで公開する

1. ZIPを解凍し、`index.html`、`assets` フォルダ、`.nojekyll` などをリポジトリの最上段に置きます。隠しファイルが表示されない場合は、表示を切り替えるか、GitHubの **Add file → Create new file** から空の `.nojekyll` を追加できます。
2. リポジトリの **Settings → Pages** を開き、**Deploy from a branch** で **`main` → `/(root)`** を選び、**Save** を押します。
3. **Visit site** から公開URLを開きます。ファイルを更新するときは、`sw.js` のキャッシュ名のバージョンも更新してください。

iPhone・iPadではSafariの共有メニューから「ホーム画面に追加」を選べます。再生履歴を移すときは、元のアプリの設定で「書き出す」を選び、新しいアプリの設定で「読み込む」を選びます。

音声はオモコロの配信元から直接再生します。番組目録はオモコロの公式記事と [omkr-radio](https://github.com/arrow2nd/omkr-radio) を参照しています。
