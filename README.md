# かまみくプレーヤー

オモコロの「かまってみくのしん」の過去回を、続きから聴くための非公式プレーヤーです。初代、GOLD、日本一、Love youの4シリーズを掲載しています。

**[かまみくプレーヤーを開く](https://osabisi.github.io/kamamiku-player/)**

リンクを開くと、ブラウザですぐに聴けます。

## ホーム画面に追加する

- **iPhone・iPad**はSafariで開き、共有メニューから「ホーム画面に追加」を選びます。「ウェブアプリとして開く」が表示されたらオンにして追加します。
- **Android**はChromeで開き、右上の「︙」から「ホーム画面に追加」を選びます。「インストール」が表示されたら選びます。

再生履歴を移すときは、元のプレーヤーの設定で「書き出す」を選び、移行先の設定で「読み込む」を選びます。

## 音源と番組目録

音声はオモコロの配信元から直接再生します。番組目録はオモコロの公式記事と [omkr-radio](https://github.com/arrow2nd/omkr-radio) を参照しています。
